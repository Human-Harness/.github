# Human Harness

Installable desktop apps that put a purpose-built interface and workflow on top of an AI agent — powered by **each user's own AI subscription**, made for people who never open a terminal.

- **[humanharness](https://github.com/Human-Harness/humanharness)** — the open-source framework (core + Socrates, the reference harness). Early design stage.

Apache-2.0 · no telemetry · your data stays in a folder you choose.
